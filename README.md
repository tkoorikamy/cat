# CatCompanion — desktop pet котик для Windows 10/11

Маленький котик поверх окон: сидит в углу, реагирует на печать и движение мыши.

## Приватность
Приложение **не записывает ввод пользователя**:
- не сохраняет текст;
- не логирует конкретные клавиши;
- не хранит историю нажатий;
- не отправляет данные в интернет.

Отслеживается только факт активности (нажата клавиша / двигалась мышь) для анимации.

## Запуск для разработчика
1. Установите Python 3.11+.
2. Запустите `run_dev.bat`.
3. Появится котик в правом нижнем углу.

## Сборка .exe
1. Запустите `build.bat`.
2. Скрипт создаст venv, установит зависимости, сгенерирует ассеты и соберёт приложение.

Готовый файл:
- обычно `dist/CatCompanion/CatCompanion.exe`.

## Управление
Через трей:
- Pause/Resume
- Change corner
- Size
- Click-through on/off
- Autostart on/off
- Exit

Fallback: правый клик по котику открывает меню (если трей недоступен).

Перемещение котика:
- зажмите **Shift** и перетаскивайте, либо включите `Toggle move mode` в контекстном меню.
